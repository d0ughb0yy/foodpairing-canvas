# Foodpairing Canvas

A personal canvas for planning dishes per *The Art & Science of Foodpairing*: add ingredient cards, give each one its aroma profile (the book's 14 aroma types with their colors), toggle the connection lines, and see which ingredients share flavors.

Run it: `npm run dev`, then open the shown URL (usually http://localhost:5173).

Tune the aroma colors and descriptor autocomplete lists in `src/config.ts`. State autosaves in the browser; Export downloads a JSON file you can Import elsewhere.
